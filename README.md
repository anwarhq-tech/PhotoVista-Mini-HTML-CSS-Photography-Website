# PhotoVista – Mini HTML/CSS Photography Website

**PhotoVista** is a mini frontend project built using **HTML and CSS**.  
The website simulates a photography portfolio, featuring a **sidebar navigation** and **gallery layout** to display photos in an elegant interface.

---

## 💡 Project Overview

This project was inspired by a tutorial, but **all code was typed manually**, and mistakes were debugged and corrected, which helped **strengthen understanding of HTML layout, CSS styling, and responsive design principles**.  

It demonstrates hands-on experience with:
- **HTML5 & CSS3 fundamentals**
- **Layout structuring** with sidebar navigation
- **Visual design and gallery interface**
- Debugging and problem-solving while coding

---

## ⚡ Features

- Responsive sidebar navigation with multiple sections
- Gallery layout to showcase photos
- Clean and modern UI design using CSS
- Fully static and lightweight (no JavaScript)

---

## 🛠 Tech Stack

- **HTML5**
- **CSS3**
